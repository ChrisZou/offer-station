# 浏览器插件

当前版本：`0.6.9`。更新后请在 `chrome://extensions` 点击插件卡片上的“重新加载”，并刷新已打开的 BOSS 页面。Chrome 会注销旧页面中的扩展上下文，因此每次重新加载开发版插件后都需要刷新已有招聘页面。

这是无需构建即可加载的 Chrome/Edge Manifest V3 插件。

本目录描述当前可运行 Demo；目标交互和技术边界见项目根目录的《浏览器插件功能与技术设计文档 V0.5》和《产品决策记录》。规划中的“收藏岗位”和“分析匹配”保持独立，插件只衔接 Web 岗位工作流，不在浮窗或侧边栏内完成简历编辑、面试准备或复盘。

加载 apps/extension 目录后，插件会以浏览器原生 Side Panel 打开。默认支持：

- BOSS 直聘职位页识别。
- 默认使用职位页浮窗，可在头像设置中切换为浏览器侧边栏。
- 头像旁提供“弹出”按钮，可从侧边栏直接切换为当前页面浮窗，不改变默认打开方式。
- BOSS 页面常驻一个收起栏；鼠标悬停和岗位切换都不会自动展开，必须点击横栏才展开。
- 浮窗“收起”会保留窄栏，“关闭”会完全隐藏；点击插件图标可再次打开。
- 收起态为会议软件风格的横向悬浮栏，可直接拖动；展开面板可通过顶部的 `•••` 把手拖动，位置会自动保存。
- 收起栏与展开浮窗共用同一位置；展开浮窗可拖动右下角调整大小。
- 浮窗允许大部分移出浏览器画面以腾出原页面空间，但顶部拖动把手始终完整保留在画面内。
- 展开与收起时以顶部 `•••` 为锚点改变尺寸，把手在屏幕上的位置保持不动。
- 调整大小时暂停 iframe 内容重排，按动画帧更新尺寸，松手后恢复卡片内容。
- 岗位卡片使用 macOS 风格的轻量层级，并采用位置、工作、学历、收藏、分析和隐私等 SF Symbols 语义图标。
- 顶部拖动把手在浮窗和收起栏中始终保持水平居中；收起与关闭使用紧凑的 macOS 风格组合按钮。
- 显示公司名称，并优先使用 BOSS 直聘页面中的公司 Logo 作为职位图标。
- 公司名称与 Logo 从同一个当前职位公司卡片成对提取；页面中的推荐职位或异常结构化数据不会覆盖当前公司。
- 默认浮窗大小为 420 × 620，可继续拖动改变大小。
- 浮窗以岗位匹配为主要功能：默认显示灰色待分析状态，手动点击后展示 Demo 匹配度、已有技能和需要改进的技能。
- 当前岗位卡不再展示完整 JD，改为简短的 AI 岗位总结 Demo。
- 匹配 Demo 暂不进行真实模型识别；正式服务统一使用服务端 `deepseek-v4-flash`，插件不保存 API Key。
- 收藏当前岗位。
- 识别失败时手动录入岗位和 JD。
- 查看最近三条收藏。
- 打开完整 Web 工作台。
- 同一职位链接重复收藏时更新原记录，不产生重复岗位。

插件默认连接已发布的公开工作台。需要本地联调时，先启动 apps/web，再点击插件右上角头像将工作台地址改为 http://localhost:3000。

切换打开方式后，下次点击浏览器工具栏中的插件图标生效。浮窗只会在受支持的 BOSS 直聘页面内显示，其他页面自动回退到侧边栏。

插件不自动投递、不读取招聘平台 Cookie、聊天、已读状态或招聘者后台信息。
